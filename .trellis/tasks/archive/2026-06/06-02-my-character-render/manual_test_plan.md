# 角色渲染 手工测试任务清单

验证 `我的背包 <服务器 ID>` / `用户背包 <服务器 ID> @某人` 卡片里的 Terraria 角色立绘。

## 前置准备
1. 一台开了 SSC 的 TShock 服务器，bot 已绑定测试账号。
2. 设置外观/装备两种方式（任选）：
   - **游戏内**：进服 → 用作弊/创造或 `/give` 拿到下表物品 → 装到对应槽 / 应用染料 → 退服存档 → 跑命令。
   - **直接改库**（更快）：编辑 `tsCharacter`，按下表槽位写入 `netID,1,0,0`。
3. SSC 槽位 / 字段对照（直接改库时用）：

| 部位 | 装备(equipment) | 装饰(vanity) | 护甲染料(dye) |
|---|---|---|---|
| 头 | Inventory[59] | [69] | [79] |
| 身 | [60] | [70] | [80] |
| 腿 | [61] | [71] | [81] |

   头发染料 = `tsCharacter.hairDye` 字段（整数索引 1–12，0=无）。配饰槽 62-68 / 72-78 / 82-88（本期不渲染）。

执行：每个用例设置好后跑 `我的背包 <服务器 ID>`，对照游戏内角色（按 ESC 看人物）核对立绘。
