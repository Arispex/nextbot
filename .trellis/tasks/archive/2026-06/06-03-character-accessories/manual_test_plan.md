# 配饰渲染 手工测试任务清单

验证 `我的背包 <服务器 ID>` / `用户背包 <服务器 ID> @某人` 卡片立绘里的**功能配饰 / 社交配饰 / 配饰染料**（在已有外观+装备+染料+发型基础上）。

## 前置
SSC 服务器 + 绑定测试账号。设置方式：游戏内装备退服存档，或直接改 `tsCharacter`（按槽位写 `netID,1,0,0`）。设好后跑 `我的背包 <服务器 ID>` 对照游戏内（ESC 看人物）。

**SSC 槽位 / 字段**：
| 用途 | 槽位 / 字段 |
|---|---|
| 功能配饰（7） | `Inventory[62..68]` |
| 社交配饰（7） | `Inventory[72..78]` |
| 配饰染料（7） | `Inventory[82..88]` |
| 隐藏可见配饰 | `tsCharacter.hideVisuals`（位掩码，bit k=3..9 隐藏功能配饰 k−3；即隐藏第 i 个功能配饰 → 加 `2^(3+i)`） |

> 配饰按物品的 `*Slot` 字段归类；无视觉 slot 的功能饰品不绘制。社交配饰逐槽覆盖功能配饰。

## 测试用例

每条：把该 netID 放入第一个功能配饰槽（62），跑命令，核对位置/层序。

| # | 类别 | netID（物品） | 期望位置 |

| A2 | 背饰 back | **1247** BeeCloak | 身后披风（在身体之后） |
| A3 | 气球 balloon | **1163** BlizzardinaBalloon | 头顶上方气球 |
| A4 | 鞋 shoe | **128** RocketBoots | 脚部 |
| A5 | 腰 waist | **15** CopperWatch | 腰/手部小物 |
| A6 | 颈 neck | **1158** PygmyNecklace | 胸前项链 |

| A8 | 盾 shield | **156** CobaltShield | 前臂侧盾牌 |

| # | 操作（62..68 多槽） | 期望 |

| B1 | 同时装 翅膀 1162 + 背饰 1247 + 气球 1163 + 盾 156 + 前饰 2284 | 翅膀/背饰/气球在身后，盾/前饰在身前，层序正确不穿插错乱 |

### C. 社交配饰覆盖（vanity 72..78 逐槽覆盖功能 62..68）
| # | 操作 | 期望 |
|---|---|---|
| C1 | 功能[62]=背饰 BeeCloak 1247，**社交[72]=前饰 CrimsonCloak 2284** | 立绘显示**社交那件**（CrimsonCloak 覆盖该槽） |

### D. hideVisuals 隐藏（功能被隐藏、社交孪生仍显示）
| # | 操作 | 期望 |

| D1 | 功能[62]=气球 1163，`hideVisuals` 加 **8**（bit3=隐藏功能配饰 0） | 气球**不显示** |

### E. 配饰染料（dye 82..88，逐槽，复用护甲染料 shader）
| # | 操作 | 期望 |
|---|---|---|

### F. 边界
| # | 操作 | 期望 |
|---|---|---|
| F1 | 无任何配饰 | 立绘与之前一致（画布虽更大，人物居中，不影响） |
| F2 | 装一个**无视觉**功能饰品（如纯数值饰品） | 立绘不变（无 *Slot 不绘制） |
